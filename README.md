# e-plantShopping

## Project Name

e-plantShopping

## Description

e-plantShopping is a Paradise Nursery online plant shopping application built with React and Redux Toolkit.

The application allows users to browse different categories of plants, view plant information, add plants to a shopping cart, update quantities, remove items, and view the total cart amount.

## Features

- Paradise Nursery landing page
- Plant categories
- Dynamic plant listing
- Add plants to cart
- Increase and decrease product quantities
- Remove products from cart
- Calculate individual item totals
- Calculate total cart amount
- Continue shopping
- Checkout option

## Technologies

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite
